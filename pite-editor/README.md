# pite-editor

Visual editor application for the [Pite](https://github.com/piteengine/pite) game engine.

Built with `egui` and `eframe`: interactive 2D scene viewport with collision wireframe rendering, scene tree hierarchy, inspector panel with byte-stable property editing, project settings, console log viewer, and integrated LSP code editor with pyright completion, hover, and diagnostics.

## Versioning

Lockstep with the engine: `pite-editor 0.x.y` is engine `0.x.y`.
