# pite-runtime

Game loop and runtime host for the [Pite](https://piteengine.github.io/pite) game engine.

Orchestrates window creation (`winit`), fixed 60 Hz physics ticks, variable rendering updates, hot reloading of scenes and scripts, input dispatching, and subsystem lifecycle management.

## Versioning

Lockstep with the engine: `pite-runtime 0.x.y` matches engine `0.x.y`.
