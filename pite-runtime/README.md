# pite-runtime

Game loop and runtime host for the [Pite](https://github.com/piteengine/pite) game engine: window creation (`winit`), fixed 60 Hz physics tick, variable rendering update, hot reloading of scenes and scripts, input handling, and subsystem orchestration.

## Versioning

Lockstep with the engine: `pite-runtime 0.x.y` is engine `0.x.y`.

## Docs

- API docs: <https://docs.rs/pite-runtime>
- Engine repo: <https://github.com/piteengine/pite>
