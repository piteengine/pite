# pite-export

Export pipeline and platform packaging engine for the [Pite](https://github.com/piteengine/pite) game engine: desktop bundle generation (Linux, Windows, macOS), launcher scripts, player binary selection, and automatic prebuilt player download fallback.

## Versioning

Lockstep with the engine: `pite-export 0.x.y` is engine `0.x.y`.

## Docs

- API docs: <https://docs.rs/pite-export>
- Engine repo: <https://github.com/piteengine/pite>
