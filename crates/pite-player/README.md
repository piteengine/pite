# pite-player

Lean standalone player binary for the [Pite](https://piteengine.github.io/pite) game engine.

Runs exported scenes directly without the editor or development tooling, providing a minimal memory footprint and instant startup times for distributed games.

## Versioning

Lockstep with the engine: `pite-player 0.x.y` matches engine `0.x.y`.
