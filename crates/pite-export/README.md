# pite-export

Export pipeline and platform packaging engine for the [Pite](https://piteengine.github.io/pite) game engine: desktop bundle generation (Linux, Windows, macOS), launcher scripts, player binary selection, and automatic prebuilt player download fallback.

## Versioning

Lockstep with the engine: `pite-export 0.x.y` matches engine `0.x.y`.
