# pite-scene

Scene format parsing (`.ptscn`), node hierarchy instantiation, validation, and binary caching for the [Pite](https://github.com/piteengine/pite) game engine.

Human-readable TOML files serve as the canonical source of truth for scenes, while optimized binary cache snapshots accelerate runtime loading. This crate depends solely on `pite-core`.

## Versioning

Published in lockstep with the engine: `pite-scene 0.x.y` corresponds to engine version `0.x.y`.
