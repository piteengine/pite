# pite-physics

2D physics subsystem for the [Pite](https://github.com/piteengine/pite) game engine powered by Rapier2D: rigid bodies, kinematic character controller with sliding obstacle collision, area triggers, collision shapes, and spatial raycasting.

Runs on a fixed 60 Hz simulation tick and dispatches to `_physics_process(delta)` in game scripts.

## Versioning

Lockstep with the engine: `pite-physics 0.x.y` is engine `0.x.y`.
