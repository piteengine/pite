# pite-physics

2D physics simulation subsystem for the [Pite](https://github.com/piteengine/pite) game engine powered by Rapier2D: rigid bodies, kinematic character controller with sliding obstacle collision resolution, area triggers, collision shapes, and spatial raycasting.

Runs on a fixed 60 Hz simulation tick and dispatches lifecycle updates to `_physics_process(delta)` in game scripts.

## Versioning

Published in lockstep with the engine: `pite-physics 0.x.y` corresponds to engine version `0.x.y`.
